THE LEARNING LOOP

It gets smarter from what you ship

Every published piece gets logged. Run a retro — with connected analytics, or by pasting your numbers — and the engine compares winners against losers, keeps only findings with real evidence, and encodes them as drafting defaults. Your voice stays yours: the loop tunes tactics, never identity.

THE QUALITY GATE

AI slop dies here

Everyone learned to avoid "delve." The tell now is shape. So the gate grades both: about 55 vocabulary patterns, plus eight structural metrics with real thresholds. Findings go back to Claude as context, so it rewrites before you ever see the draft.

Try it. This runs the gate's core rules in your browser.
em-dash density> 1.5 per 100 words
"not X, but Y"2 or more contrast constructions
rhetorical questions> 15% of sentences
tidy triples3+ "A, B, and C" single-word lists
sentence rhythmlength variation (cv) < 0.30
paragraph shapelength variation (cv) < 0.25
formulaic closer"in conclusion", "what do you think?"
readabilityFlesch-Kincaid grade > 13

Every metric has a minimum sample size, so short pieces and normal human variation don't trip it. Prose is extracted first: code, headings, lists, and tables are ignored. The project's own README is a regression test and has to pass clean.

local-first

Memory, banned phrases, learnings: plain files in ~/.claude-content-engine/. Delete the folder and it's gone. Nothing leaves your machine except what you send to the model.

tested + CI

30 tests run on every push. The README is a fixture: real human prose has to pass the gate clean, so a threshold can't drift without breaking the build.

yours to edit

Every threshold is a named constant. Every skill is markdown. Fork it, tune it, ban your own words.
